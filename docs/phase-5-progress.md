# 第五阶段进度

## 已完成：追踪钱包列表（本地第一批）

- 首页「追踪钱包」按钮或 `/track` 命令打开列表，分页显示备注和地址。
- 添加地址：一次可发送多行，每行「地址 备注」，备注可省略，最长 20 个字。可以把导出的列表整段粘贴回来导入。
- 查看单个地址：显示备注、地址，以及当前链的原生币余额（只读，可刷新）。
- 删除：从追踪列表移出，不影响链上任何数据。
- 导出列表：发送纯文本，每行「地址 备注」，方便备份或转给其他设备导入。
- 列表最多 50 个地址。地址格式不对的行会被跳过并说明。重复地址不会重复添加。
- 追踪列表保存在本地状态文件中，与其他设置一起保存。

这一批只是记录地址，不会自动买卖、不会自动跟单、不会发送通知。

## 未完成与限制

- 交易和创建事件的通知：需要可靠的链上事件来源（节点日志或索引服务）。免费节点的限额和稳定性未核实，暂不做，避免误报或漏报。
- 钱包跟单：涉及自动买卖真实资金，需要先有可靠的事件检测、去重和金额上限，并单独确认授权。本批次不做。
- 开发者卖出监听：依赖可验证的开发者地址和卖出事件检测，本批次不做。
- 新币与迁移监控：需要新池和迁移事件来源，本批次不做。
- 标签的颜色、按链筛选：暂不做，列表只保存地址和备注。
- 备注只能在删除后重新添加来修改。
- 本批次只做了类型检查，按要求没有运行测试。
