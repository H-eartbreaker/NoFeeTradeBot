# 第一期：中文交易界面、设置和买前确认

本期代码已完成。本地类型检查、28 项自动测试以及 BSC / Base / ETH / Robinhood 四链真实数据界面测试通过；未发送真实交易、未重启当前机器人。

## 怎么使用

在运行机器人的终端按 `Ctrl + C`，再运行 `npm start`。重新打开机器人，点击菜单里的“打开交易终端”（或发送 `/start`）。

首页按钮：买入 / 查看代币、持仓与余额、切换交易链、设置、止盈止损、使用说明。

### 设置不需要手打命令

1. 点“设置”，选择要修改的链。
2. 点“买入滑点”或“卖出滑点”，直接回复 `30` 或 `30%`。
3. 点“买入按钮金额”，直接回复 `0.001 0.002 0.003`；单位是当前链的原生币，支持 1～6 档。
4. 点“卖出按钮比例”，直接回复 `12.5 50 100`；支持小数比例及 1～6 档。
5. 输入错误可重新填写，发“取消”或点“取消”退出；输入 5 分钟内有效。其他命令或菜单会退出当前输入。

滑点支持 0.01～99.99%。各链的买入滑点、卖出滑点、按钮和买前确认互不影响。图表入口、区块浏览器入口、时区和 12/24 小时制是全局显示设置。

旧文件中的全局滑点会作为各链未单独配置时的默认值保留。“恢复本链默认”不会改变其他链、已有持仓或已有止盈止损规则，且需要再次点确认。

### 买入前确认

默认开启，可在所选链的设置里关闭。点击买入金额后，先显示：

- 链、代币名字/符号和完整 CA。
- 本次买入金额、预计收到、滑点和按报价计算的最低可接受数量。
- 貔貅检测结果、买入税和卖出税；不能检测时显示未知。
- 报价经过的 DEX 和池地址；超过 6 个池可查看全部池详情。

点击“确认买入”才执行交易。确认 60 秒内有效，只能使用一次；重复点击、取消、改动相关设置、过期或重启后的旧确认不能再次下单。

实际提交前重新读取代币/风险信息和报价。税费、名称、代币精度或交易池发生变化，需要重新确认；新报价不能将确认页的最低可接受数量再次降低。在队列中等待到过期也不会发送交易。

关闭二次确认只省去确认页，貔貅检查仍然存在。检测未知并不代表安全；Robinhood 当前没有貔貅检测服务。

### 自定义买卖

发送 CA 后，点击“自定义买入”，直接回复金额；点击“自定义卖出比例”，直接回复百分比。

输入绑定原来那张卡片的链和 CA，不依赖之后切换到的链。预设金额改变后，旧卡片上的买入按钮会提示刷新，避免显示金额与实际买入金额不一致。

交易成功后刷新原交易卡片。Telegram 消息更新失败不会把已经成交的交易误报为交易失败。

### 快速买入

默认关闭。所选链的设置里可开启；开启前有说明和确认。

开启后，发送包含 CA 的消息会使用当前第一档金额准备买入。若买前确认开启，仍必须确认；只有显式关闭买前确认后，才会直接提交交易。

### 止盈止损

点首页“止盈止损”，直接回复 `100 30`，表示新买入默认赚 100% 或亏 30% 全卖。发 `off` 关闭新买入默认规则。

此默认规则仍适用于所有链的新买入，不会重写已有仓位的规则。自动卖出现在使用该仓位所在链的卖出滑点。
