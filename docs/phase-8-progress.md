## 已完成：Solana 买卖和持仓（第一版）

- 统一入口：「切换交易链」选择 Solana；沿用 demo bot 首页，不再单独放「Solana 买卖」按钮。`/sol` 保留为兼容入口，也会切换到统一首页。
- 生成钱包：机器人在本机生成 Solana 私钥，写入本地 `.env`（权限 600），不会在 Telegram 显示。已有 Solana 私钥时不会覆盖。
- 查看代币：发送 Solana 代币地址（Mint），弹出卡片，显示名称、符号、精度、增发权限、冻结权限和你的持仓。
- 买入：0.01 / 0.05 / 0.1 SOL 三个档位，或自定义金额（最多 100 SOL，最多 9 位小数）。
- 卖出：默认 25% / 50% / 100%，可配置按钮或输入 0.01～100% 的自定义比例；确认时固定报价数量，执行前若持仓变化需重新确认。
- 买前确认默认开启，可在统一设置关闭；快速买入默认关闭，开启前另有确认。关闭买前确认后，手动点买入或快速买入会直接发送交易。卖出仍需确认。确认页包括链、名字、CA、金额、滑点、预计收到、实际路由池，以及权限与税费未知提示，60 秒有效。
- 报价和交易使用 Jupiter lite-api；交易由本机签名后经 Solana RPC 发出。
- 滑点默认 1%，在统一「设置」中分别改买入和卖出滑点、按钮金额与比例、买前确认、快速买入，以及共用显示/时区设置。旧 Solana 滑点作为未设置时的回退，恢复默认则重置为 1%。
- 同一钱包的买卖按顺序执行，不会同时抢同一份余额。
- 余额保留：买入时钱包需要至少留 0.01 SOL 作为手续费和账户租金；卖出时 SOL 至少 0.005 SOL 用于手续费。
- 发出后等待确认最长 2 分钟。链上明确失败会显示原因；超时未确认会显示签名和 Solscan 链接，不会自动重发。只有过了交易有效期仍查不到记录，才会判定为未成交。

## 未完成与限制

- 止盈止损、自动订单、追踪钱包对 Solana 暂不支持，后续再做。
- `/history` 不显示 Solana 交易，盈亏（PnL）不计算 Solana。
- 蜜罐检测：Solana 暂不支持，卡片显示「未检查」。
- 价格影响（price impact）暂不显示：Jupiter 返回字段的单位未核实。
- Token-2022 扩展（例如转账税）暂不检查。
- 优先费使用 Jupiter 的 `auto`，没有设上限。
- lite-api 没有服务级别保证，报价或交易可能失败。
- 私钥只在启动时从 `.env` 读取。生成后当前进程可以直接使用；如果同时运行多个机器人进程，其他进程需要重启。
- 界面改动需要重启机器人才能生效：先 Ctrl+C，再 `npm start`。
- Solana 不接入自动规则，所有买卖都是手动确认。

## 统一界面与切链保护（2026-10-29）

- 链选择、设置页链标签和 Logo 管理都包含 Solana；首页按钮结构与其他链一致。
- 余额页加入 SOL 余额与 Solana 地址，避免把 EVM 地址当作 Solana 充值地址。
- 选中 Solana 时，钱包管理、充值、持仓入口及对应命令走 Solana；未生成钱包时提供本机生成入口。
- Solana 第一版仍只有一个主钱包，独立于 EVM 的多钱包。盈亏、交易记录、授权、资金转出/跨链、订单与追踪尚未接入，不伪造结果，也不回退到 BNB。
- 买入最多 100 SOL、9 位小数；默认 0.01/0.05/0.1 SOL；买卖按钮都可配 1～6 档。
- 切链清理旧输入、自动单创建草稿和买前确认；旧 Solana 卡片不能在其他链下单，旧 EVM 卡片不能在 Solana 下单。
- 交易确认绑定 Solana 地址、设置、界面切链版本和报价。进入队列、签名、发送前均检查是否仍有效，防止排队期间切链或超时后发送。
- 已确认报价直接用于生成交易，不在确认后悄悄换另一条路由。交易是否成交以链上结果为准。
- 目前只做类型检查，不跑交互测试、不访问真实报价、不生成真实钱包、不发交易；待测项见 `test-guide.md`。
