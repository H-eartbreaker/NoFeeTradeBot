## 已完成：Solana 买卖和持仓（第一版）

- 入口：首页「Solana 买卖」按钮或 `/sol` 命令。
- 生成钱包：机器人在本机生成 Solana 私钥，写入本地 `.env`（权限 600），不会在 Telegram 显示。已有 Solana 私钥时不会覆盖。
- 查看代币：发送 Solana 代币地址（Mint），弹出卡片，显示名称、符号、精度、增发权限、冻结权限和你的持仓。
- 买入：0.01 / 0.05 / 0.1 SOL 三个档位，或自定义金额（最多 100 SOL，最多 9 位小数）。
- 卖出：25% / 50% / 100% 持仓。执行时按当时余额计算。
- 每笔都要点确认。确认页写明链（Solana）、代币名称和地址、金额或比例、滑点。确认页 60 秒内有效，过期需重新操作。
- 报价和交易使用 Jupiter lite-api；交易由本机签名后经 Solana RPC 发出。
- 滑点默认 1%，可在「Solana 买卖」里的「滑点」修改（0.01 到 99.99）。
- 同一钱包的买卖按顺序执行，不会同时抢同一份余额。
- 余额保留：买入时钱包需要至少留 0.01 SOL 作为手续费和账户租金；卖出时 SOL 至少 0.005 SOL 用于手续费。
- 发出后等待确认最长 2 分钟。链上明确失败会显示原因；超时未确认会显示签名和 Solscan 链接，不会自动重发。只有过了交易有效期仍查不到记录，才会判定为未成交。

## 未完成与限制

- 止盈止损、自动订单、追踪钱包对 Solana 暂不支持，后续再做。
- `/history` 不显示 Solana 交易，盈亏（PnL）不计算 Solana。
- 蜜罐检测：Solana 暂不支持，卡片显示「未检查」。
- 价格影响（price impact）暂不显示：Jupiter 返回字段的单位未核实。
- Token-2022 扩展（例如转账税）暂不检查。
- 优先费使用 Jupiter 的 `auto`，没有设上限。
- lite-api 没有服务级别保证，报价或交易可能失败。
- 私钥只在启动时从 `.env` 读取。生成后当前进程可以直接使用；如果同时运行多个机器人进程，其他进程需要重启。
- 界面改动需要重启机器人才能生效：先 Ctrl+C，再 `npm start`。
- Solana 不接入自动规则，所有买卖都是手动确认。
