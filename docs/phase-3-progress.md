# 第三阶段进度

## 已完成：止盈止损升级（第一批）

- 分档止盈：`50/50 100/100` 表示涨 50% 卖出当前余额的 50%，再涨 100% 卖出剩余。每轮最多触发一档，按顺序执行，档数随仓位保存。
- 固定止损 `sl30`、移动止损 `trail20`（从观察到的最高价回撤 20% 全部卖出，仅在价值高于成本后启用）。
- 优先级：固定止损 > 移动止损 > 分档止盈。原有「100 30」格式保持不变。
- 部分卖出后，成本、最高价和档数与卖出数量一起保存，崩溃重启后同一档不会重复卖出。
- 确认超时或到账数据不全的分档卖出同样推进进度，并阻止重复执行同一档。
- 「全局暂停自动订单」：暂停后监控不再自动卖出，手动卖出不受影响；可在止盈止损页面恢复。

本轮验证：类型检查通过；89 项离线测试通过（含分档、移动止损、优先级、暂停、成交但到账不全、规则解析和拒绝无效输入）。测试使用临时账本和模拟链上读取/卖出，未发送真实交易。
