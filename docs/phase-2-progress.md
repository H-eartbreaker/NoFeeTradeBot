# 第二阶段进度

## 已完成：钱包与交易账本基础

- 旧 `PRIVATE_KEY` 保留为主钱包；新增钱包分别记录持仓、成本和规则。
- 新私钥只写入本地 `.env`，权限 0600；保存操作加锁，避免两个程序覆盖新增钱包。
- 每个钱包、每条链独立排队；同钱包同链继续串行，避免 nonce 冲突。
- 交易 hash 在等待回执之前保存到 `data/trades.jsonl`。确认超时保留待确认状态，并阻止此钱包在该链重复广播；之后只读查询回执恢复。
- 成交按 hash 去重；主流程和恢复流程都不会重复累加成本。状态或账本损坏时停止并保留文件，不自动清空。
- Gas 单独记账；Base / Robinhood 若回执未提供 L1 费，标记费用不完整，不声称是总费用。
- 不确定交易结果时自动规则暂停，避免把超时当作失败后重复卖出。

本轮验证：类型检查，35 项离线测试通过。测试使用临时目录和固定测试私钥，Telegram 与广播均被拦截。未修改真实钱包配置或正式持仓数据，未运行机器人、未花费资金。

## 已完成：钱包和交易记录菜单

- 首页增加「钱包管理」「交易记录」，命令菜单增加 `/wallets`、`/deposit`、`/history`。
- 钱包列表支持分页。详情显示各启用链余额，支持刷新和选择默认钱包，重启保留默认选择。
- 创建新钱包需确认，60 秒有效；双击、过期、取消、其他命令和重启后的旧确认不会重复创建。新钱包保留在本机，默认选择不自动改变。
- 切换默认钱包时废弃尚未执行的买入确认；旧代币卡片继续绑定其原钱包，新的 CA 使用默认钱包。
- 充值页显示当前钱包地址和可用网络，同地址在各链的余额独立。
- 导入在项目终端执行 `npm run wallet:import`，私钥输入隐藏，不接收命令行私钥参数或非交互管道，不打印私钥；导入后重启机器人再选择钱包。
- 记录按钱包和链隔离、每页五条，显示实际已记录的金额、状态、Gas 和浏览器链接。确认中/未知状态明确提示勿重复提交，L2 缺失费用不称为完整费用；不把旧版没有记录的历史当成零成本。

本轮验证：类型检查与 48 项离线测试通过。额外使用伪终端运行本地导入脚本，只访问临时测试 `.env`，确认隐藏输入和 0600 权限。未启动或重启真实机器人，未创建真实使用的钱包，未发起链上交易；Telegram 外观和真实新钱包首次交易仍待使用中核对。

## 已完成：资金入口和功能图标

- 功能按钮采用统一图标：钱包 👛、资产 📊、记录 📜、转账 📤、兑换 🔄、跨链 🌉、设置 ⚙️，链按钮保留已导入的自定义 Logo。
- 首页增加「转账 / 兑换 / 跨链」，也可使用 `/funds`。先在首页选择钱包与链，操作过程中直接回复地址和金额；资金操作始终单独确认，不受买前确认开关影响。
- 当前转账支持本链原生币及以下稳定币；兑换支持这两种币双向互换：BSC BNB/USDT、Base ETH/USDC、Ethereum ETH/USDT、Robinhood ETH/USDG。所有代币按合约精度解析，不将 USDT 默认当作六位精度。
- 转账确认展示完整收款地址、支出币合约、金额、来源链和执行 Gas 预算。余额不足、过期、Gas 超预算时拒绝广播。
- 兑换绑定确认页的路由和最低输出，执行前重新核对。不足的稳定币授权仅覆盖本次数量，旧非零额度先清零以兼容 USDT。最多两次授权和兑换共用预算，L2 的 L1 数据费单独说明，不称为总费用上限。已完成的授权可能先产生 Gas，之后取消或行情变化不会自动撤销授权。
- 跨链使用 Relay 的原生币到原生币路线，来源和目标链可以使用不同币种（例如 BNB → Base ETH），只发往同一钱包。确认展示服务费、服务报价最低到账、预计时间和来源链合约；无法核对零平台附加费或需要额外签名/多步骤的路线拒绝执行。
- 跨链来源链回执和目标链状态分别记录；报价输出不当作实收。每 15 秒独立检查最多三笔跨链，轮换待处理记录，避免拖慢 3 秒止盈止损。重启从账本恢复查询，只读核对，绝不补发交易。服务报告到账/退款/异常时尽力通知，仍需链上核对。
- 所有确认 60 秒内有效、单次消费；取消、切换菜单、修改设置不会复用旧输入，报价等待期间取消也不会出现迟到确认。发送结果不确定时保存 hash 并阻止重复广播；消息失败不误报链上失败。
- 账本增加转账币种精度、兑换输出、跨链请求与独立状态的展示，兼容已有记录，无正式数据迁移。

本轮验证：先通过全部 59 项离线测试；最终补充取消等待与跨菜单退出测试后，类型检查与 35 项相关回归测试通过（其他未变化测试沿用上一轮结果）。`scripts/funds-smoke.ts` 使用固定测试地址和只读客户端，四链稳定币精度、双向报价和构建通过；跨链报价 BNB→Base、Base→BNB、ETH→Base、Robinhood→Base 通过。未读取真实 `.env`、未签名、未发 Telegram 消息、未执行真实资金操作，也未重启机器人。
