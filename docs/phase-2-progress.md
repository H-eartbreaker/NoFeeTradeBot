# 第二阶段进度

## 已完成：钱包与交易账本基础

- 旧 `PRIVATE_KEY` 保留为主钱包；新增钱包分别记录持仓、成本和规则。
- 新私钥只写入本地 `.env`，权限 0600；保存操作加锁，避免两个程序覆盖新增钱包。尚未启用创建钱包的 Telegram 入口。
- 每个钱包、每条链独立排队；同钱包同链继续串行，避免 nonce 冲突。
- 交易 hash 在等待回执之前保存到 `data/trades.jsonl`。确认超时保留待确认状态，并阻止此钱包在该链重复广播；之后只读查询回执恢复。
- 成交按 hash 去重；主流程和恢复流程都不会重复累加成本。状态或账本损坏时停止并保留文件，不自动清空。
- Gas 单独记账；Base / Robinhood 若回执未提供 L1 费，标记费用不完整，不声称是总费用。
- 不确定交易结果时自动规则暂停，避免把超时当作失败后重复卖出。

本轮验证：类型检查，35 项离线测试通过。测试使用临时目录和固定测试私钥，Telegram 与广播均被拦截。未修改真实钱包配置或正式持仓数据，未运行机器人、未花费资金。
