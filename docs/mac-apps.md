# 双击启动和停止（Mac）

项目文件夹里有两个应用：**启动机器人.app**、**停止机器人.app**。

- 双击「启动机器人」，看到成功提示后去 Telegram 使用。不需要打开终端。
- 更新代码后，先双击「停止机器人」，再双击「启动机器人」。
- 提示框关闭后，后台机器人会继续运行；退出登录、关机和电脑休眠会影响运行。
- 这两个应用要留在项目文件夹里。可以把它们拖到 Dock 或在桌面放替身，不能只移动应用本身。
- 启动器不会设置开机自启，不会自动生成钱包或发交易。启动后，之前已启用的自动订单和止盈止损会照常恢复。
- 错误记录位于 `data/mac-bot.log`，私钥仍在 `.env`，不要把 `.env` 发给别人。
- 如果旧版机器人仍从终端运行，启动器会拒绝重复启动；停止按钮只结束工作目录为本项目的机器人，不结束其他项目。

重建应用：开发 Agent 可执行 `zsh scripts/build-mac-apps.zsh`。生成的 `.app` 不纳入 Git，源码脚本纳入 Git。

## 留给验收 Agent

按用户要求，未实际点击或执行启动/停止，以免干扰当前机器人。已做脚本语法检查和应用编译。

在用户允许重启时验收：首次启动与成功提示、重复双击不重复启动、终端旧进程识别、停止后退出、更新后重新启动、无代理时提示、路径含空格或中文、配置缺失、关提示框后后台仍运行。不要在验收时发真实交易。
