# 交易机器人（Telegram 多链交易终端）

[English](README.md) | 中文

这是一个运行在你自己电脑上的 Telegram 交易机器人。你在 Telegram 里发送代币合约地址、点按钮就能买卖，同时可以设置止盈止损和自动订单。它支持 BNB Chain、Base、以太坊主网、Robinhood Chain 和 Solana。

> **风险提示**：这是个人自用工具，不是投资建议，也不是托管服务。链上交易可能亏损，代币可能是骗局、貔貅盘或流动性极差的项目。请只使用专用小额热钱包，并且先用小金额测试。作者不对资金损失负责。

## 产品介绍

机器人只在你的电脑上运行，使用你自己的 Telegram 账号和你自己的钱包。它不是托管平台，不收取平台抽成。

- **只服务一个人**：只有 `.env` 里 `ALLOWED_USER_ID` 指定的 Telegram 用户可以操作；其他人的消息和按钮回调都会被拒绝。
- **私钥只在本地**：私钥保存在项目目录的 `.env` 文件中（权限 600），不会发送到聊天或日志。
- **先确认再交易**：买入前可以开启确认页，核对链、代币地址、池子、税费和滑点后再提交。
- **自动规则需要机器人在线**：止盈止损和自动订单由本地进程执行，电脑关机、休眠或机器人停止时都不会执行。

| --- | --- | --- |

| 自动订单（`/orders`） | 限价单、市值单、定投；支持取消、暂停、过期，结果不明时不自动重发 | 已接入并有测试 |

| 授权管理（`/approvals`） | 查询本地记录代币的 Kyber 授权额度，并可撤销为 0 | 已接入；真实撤销未在本轮验证 |

| 资金操作（`/funds`） | 转账、稳定币兑换、跨链（Relay） | 已接入；本轮只验证报价和未签名构建 |
| Solana | 余额与持仓、签名账本、盈亏、自动止盈止损、自动订单；可选 Jito 保护（需手动设置小费，默认关闭） | 已接入并有测试；主网真实交易未验证 |

## 安装

### 1. 准备

- **Node.js**：测试环境为 Node 26。项目通过 `node src/index.ts` 直接运行 TypeScript，请使用支持类型剥离的较新版本。
- **Telegram 机器人 token**：在 Telegram 里找 [@BotFather](https://t.me/BotFather) 创建机器人，拿到形如 `123456:ABC...` 的 token。
- **你的 Telegram 数字 ID**：用 [@userinfobot](https://t.me/userinfobot) 查询。
- **一个专用钱包**：只放小额资金，不要使用主钱包。可以让安装脚本自动生成，也可以导入已有私钥。
- **Gas 币**：各链交易需要对应链的原生代币（BNB、ETH）作为 Gas。

### 2. 下载并安装依赖

```bash
git clone <仓库地址> 交易机器人
cd 交易机器人
npm install
```

### 3. 生成 `.env`

```bash
node scripts/setup.ts
```

按提示输入 Telegram token、你的数字 ID；私钥可以直接回车，让脚本生成新钱包。脚本会打印钱包地址，往这个地址充值即可。

如果 `.env` 已存在，脚本会退出，不会覆盖。要重来请先手动删除或重命名 `.env`。

也可以手动复制 `.env.example` 为 `.env` 再填写。

### 4. 启动

```bash
npm start
```

启动后，在 Telegram 里给机器人发送 `/start`。

### 5. Mac 双击启动（可选）

```bash
zsh scripts/build-mac-apps.zsh
```

会在项目目录生成「启动机器人.app」和「停止机器人.app」。双击启动会在后台运行机器人，错误信息写入 `data/mac-bot.log`。这两个应用要留在项目文件夹里，不能只移动应用本身。启动器不会设置开机自启。

## 配置说明

`.env` 中的主要配置（完整示例见 `.env.example`）：

| 变量 | 必填 | 说明 |
| --- | --- | --- |
| `TELEGRAM_BOT_TOKEN` | 是 | BotFather 给的 token |
| `ALLOWED_USER_ID` | 是 | 允许操作机器人的 Telegram 数字 ID |
| `PRIVATE_KEY` | 是 | 专用热钱包私钥（`0x` 开头，64 位十六进制） |
| `CHAINS` | 否 | 启用的链，逗号分隔：`bsc`、`base`、`eth`、`rh`。第一个是默认链 |
| `RPC_URL` | 否 | 第一个链的自定义 RPC；也可用 `RPC_URL_BSC` 等单独设置 |
| `BUY_AMOUNTS_BSC` 等 | 否 | 覆盖某条链的买入档位，例如 `0.001,0.002,0.003` |
| `DEFAULT_SLIPPAGE_PCT` | 否 | 默认滑点百分比，默认 10，支持 0.01～99.99 |
| `SOLANA_RPC_URL` | 否 | Solana RPC，默认使用官方公共节点 |
| `SOLANA_PRIVATE_KEY` | 否 | Solana 私钥，由机器人在 Telegram 的 Solana 页面生成并写入，不要手动粘贴到聊天里 |
| `HTTPS_PROXY` | 否 | 本地代理地址，例如 `http://127.0.0.1:7897`。如果你的网络需要代理才能连 Telegram，请设置 |

## 常见问题

**Q：机器人会自动替我交易吗？**
A：默认不会。买入需要你在 Telegram 里点击确认；自动规则（止盈止损、自动订单）需要你在界面里明确设置并启用。

**Q：电脑关机或休眠后，止盈止损还会执行吗？**
A：不会。机器人是一个本地进程，停止期间规则不会执行。重新启动后，之前启用的规则会恢复。

**Q：私钥安全吗？**
A：私钥以明文保存在 `.env` 中，文件权限为 600，只有你的系统用户能读。它不会发送到 Telegram、日志或仓库。但任何能读取你电脑文件的程序都能拿到它，所以请只放小额资金，不要复用主钱包私钥。

**Q：为什么 Robinhood Chain 没有貔貅检测？**
A：当前没有可用的检测接口，貔貅状态会显示为未知，请自行判断风险。

**Q：为什么有时买入被拒绝，提示数据未知？**
A：如果你在买入风控设置里开启了某一项检查（如税费、貔貅检测），拿不到该项数据时机器人会拒绝买入，避免在无法核对时误买。关闭对应检查即可放行，但风险需要你自己承担。

**Q：机器人不回复 Telegram 消息怎么办？**
A：先确认 `npm start` 的输出里有没有连接错误。如果你的网络需要代理，请在 `.env` 里设置 `HTTPS_PROXY`，然后重启机器人。

**Q：有平台抽成或订阅费吗？**
A：没有。你只需要支付链上 Gas、DEX 和路由的手续费，以及跨链或 Jito 小费（如果启用）。

**Q：支持跟单吗？**
A：目前不支持。`/track` 只记录地址和备注，计划中的钱包监控跟单还没有实现。

**Q：支持内盘（Four.meme、Flap、Pump.fun）吗？**
A：目前不支持，代码中没有对应实现。

**Q：Windows 或 Linux 能用吗？**
A：未测试。Mac 双击脚本只适用于 macOS；直接用 `npm start` 理论上可以，但没有在其他系统上验证。

**Q：我把 `.env` 发给别人了，怎么办？**
A：立即把对应钱包里的资金转移到新的钱包，在 BotFather 里重新生成 Telegram token，并更换 `.env` 中的私钥。

## 安全说明

- 不要把 `.env`、`data/` 目录或任何私钥提交到 Git（已在 `.gitignore` 中忽略）。
- 不要把真实私钥粘贴到 Telegram 聊天里。
- 只在你信任的电脑上运行，并保持系统和 Node 更新。
- 发现私钥或 Token 泄露时，请立即转移资金、更换 Token 和私钥。
